# おこづかい管理くん

毎日のミッション（お手伝いや勉強など）の達成状況に応じておこづかいをかんたんに記録・管理できる、モバイル最適化された **カレンダー型PWAアプリ** です。

---

## 主な機能

- **家族・対象者ごとの管理（マルチユーザー対応）**
  - お子さまやご家族など、複数の対象者を登録して **「〇〇のお小遣い帳」** として個別に記録・集計・分析できます。
  - メイン画面上部の切り替えバーから **1タップで対象者を切り替え** ながらサクサク入力でき、**「+ 追加」** からその場で対象者を追加することも可能です。
  - 設定画面から対象者の追加・名前やアイコンの編集・削除（記録ごとの削除）を行えます。
- **カレンダー画面（メイン画面）**
  - 上部に選択中の対象者名（`〇〇のお小遣い帳`）と切り替えバーを表示します。
  - 月ごとのカレンダー上に各日の獲得金額を表示します。
  - 上部に **当月合計** と **総計** をまとめて表示し、月単位・通算の金額を一目で確認できます。
  - 登録完了時には、増減した金額のロールアニメーション・通知・カレンダーセルの強調演出が動作します。
- **おこづかい登録（単日 / 期間一括）**
  - 事前登録されたミッション一覧から **「達成」** ボタンをタップするだけで金額を自動計算します。
  - **「x1」ボタン** をタップするたびに倍率（`x1`, `x2`, `x3`, ...）が増え、量や回数に応じた金額入力が可能です。
  - **期間一括登録** では開始日〜終了日を指定してまとめて記録でき、入力済みの日付が含まれる場合は該当日の確認ダイアログを表示してから上書きします。
- **お小遣い帳（履歴）・分析・設定**
  - **お小遣い帳**: 選択中の対象者の合計残高と、直近の履歴（新しい順に最大5件）を確認できます。
  - **分析**: 選択中の対象者のミッション別獲得内訳（円グラフ）と、過去1年間の月別獲得金額（棒グラフ）を表示します。
  - **設定**:
    - 対象者（家族）の追加・編集・削除
    - 対象者ごとの おこづかい項目（ミッション）の追加・編集・削除
    - 任意の金額を指定したおこづかいの追加・減少（お年玉やお買い物の記録）
    - 記録データの **CSVダウンロード**（対象者別 / 全員分まとめ、UTF-8 BOM付き）
- **PWA・スマホ操作最適化**
  - ダークモードをデフォルト採用（ヘッダーからライトモードへ切り替え可能）。
  - 登録履歴・金額調整データは **IndexedDB**、対象者設定・選択状態・テーマ設定・対象者別ミッション項目設定は **localStorage** に自動保存され、オフラインでも動作します。
  - iOS / Android のホーム画面に追加して、ネイティブアプリのように利用できます。

## 基本的な操作方法

### 1. 対象者を切り替える・追加する
1. カレンダー画面上部の切り替えバーから対象者のボタンをタップすると、即座にその人の **「〇〇のお小遣い帳」** に切り替わります。
2. 新しい対象者を追加したいときは、切り替えバー右端の **「+ 追加」** または **「設定 → 対象者（家族）の管理」** から名前とアイコンを登録できます。

### 2. 1日分のおこづかいを登録する
1. カレンダー画面で記録したい日付をタップします（今日の分は **「本日分を登録する」** からすぐ開けます）。
2. 達成したミッションの右横にある **「達成」** ボタンをタップします。
   - 複数回・複数個こなした場合は、左隣の **「x1」** ボタンをタップして倍率（`x2`, `x3`…）を上げます（2倍以上のときは「−」ボタンで戻せます）。
3. 画面下部の合計金額を確認し、**「登録する」** をタップすると保存してカレンダー画面へ戻ります。

### 3. 複数日をまとめて登録する（期間一括登録）
1. カレンダー画面の **「期間一括登録」** をタップします。
2. **開始日** と **終了日** を指定し、達成したミッションと倍率を選択します。
3. **「一括登録する」** をタップします（すでに入力済みの日付が含まれる場合は確認ダイアログが表示されます）。

### 4. 履歴・分析・設定を使う
1. カレンダー画面の **「分析・設定」** をタップすると、選択中のお小遣い合計と最新の履歴（最大5件）が表示されます。
2. 画面下部のボタンから **「分析」**（グラフ確認）または **「設定」**（対象者管理・項目編集・金額調整・CSV出力）へ移動できます。

### 5. スマホのホーム画面に追加する（PWA）
- **Android / PC（Chrome 等）**: ヘッダーに表示される **「アプリ追加」** ボタン、またはブラウザメニューの「ホーム画面に追加 / インストール」から追加できます。
- **iPhone / iPad（Safari）**: ヘッダーの **「ホームに追加」** ボタンの案内、または Safari 下部の共有ボタン → **「ホーム画面に追加」** を選択してください。

## 技術構成

- **フロントエンド**: React 19 / TypeScript / Vite / Tailwind CSS v4 / Lucide React
- **データ永続化**: IndexedDB（対象者別の日別登録記録・手動金額調整データ） / `localStorage`（対象者リスト・選択中の対象者・テーマ設定・ミッション項目設定）
- **PWA**: Web App Manifest（`public/manifest.json`） / Service Worker（`public/sw.js`・自動キャッシュ更新対応）

## 開発・デプロイ手順

### ローカル開発

```bash
npm install
npm run dev
```

### ビルド・型チェック

```bash
npm run lint
npm run build
```

### GitHub Pages への自動デプロイ

本リポジトリには GitHub Actions ワークフロー（`.github/workflows/deploy.yml`）が含まれています。

1. GitHub リポジトリにコードを push します（`main` または `master` ブランチ）。
2. GitHub リポジトリの **Settings → Pages** を開き、**Build and deployment > Source** を **「GitHub Actions」** に設定します。
3. 以降の push ごとに自動でビルドおよび GitHub Pages への公開が行われます。
